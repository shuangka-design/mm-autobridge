# Money Manager AutoBridge - Safe Mode (ไร้ AccessibilityService 100%)

เวอร์ชันนี้ **ตัด `AccessibilityService` ออกทั้งหมด** เพื่อให้ใช้งานร่วมกับแอปธนาคารไทยทุกค่าย (**กรุงไทย Krungthai NEXT, กรุงเทพ BualuangM, กรุงศรี KMA, ออมสิน MyMo, และ TrueMoney**) ได้อย่างปลอดภัย 100% โดยไม่มีการแจ้งเตือนให้ปิดการช่วยเหลือพิเศษ

## การทำงาน 2 ระบบคู่กันในแอปเดียว
1. **โหมดทันใจ (Copy & Quick-Launch):**
   - เมื่อโอนเงินหรือมีสลิปใหม่บันทึกในเครื่อง แอปจะอ่านยอดเงินและเด้งแจ้งเตือนด้านบนจอทันทีว่า **"💸 จ่ายผ่าน [ชื่อธนาคาร]: 150.00 บาท - แตะที่นี่เพื่อคัดลอกยอด & เปิดแอปหมูแดง"**
   - เมื่อคุณแตะที่แจ้งเตือนนั้น แอปจะ **คัดลอกตัวเลข `150.00` ลงแป้นพิมพ์ (Clipboard)** และ **เปิดแอป Money Manager (หมูสีแดง)** ขึ้นมาให้ทันที คุณแค่กดวาง (Paste) แล้วกดบันทึกได้เลย
2. **โหมดสะสมทั้งวัน (Auto-Collect & Export `.xls`):**
   - ทุกครั้งที่คุณใช้จ่าย แอปจะแอบจดบันทึก **วันเวลา, ธนาคาร, ชื่อร้านค้า, และยอดเงิน** สะสมไว้ในแอปให้อัตโนมัติแม้คุณไม่ได้กดแจ้งเตือน
   - ตอนเย็นหรือสิ้นสัปดาห์ คุณสามารถกดปุ่ม **"📥 สร้างไฟล์ .xls"** ในแอป เพื่อนำเข้า (Import) รายการทั้งหมดเข้าแอปหมูแดงรวดเดียวได้ทันที!
